# php-8.6 deferred extensions

Extensions that do **not** build against PHP 8.6 yet. Their yamls are kept ready
here (versions as of the 8.5 set); when upstream adds 8.6 support, apply the
"what to do" step and open a PR adding the files to `php/8.6/` and `php/8.6-zts/`.

Common PHP 8.6 breaking changes for extensions: `XtOffsetOf` removed (use `offsetof`),
`zval_dtor` removed, `php_verror` signature changed, `INI_INT`/`INI_BOOL` removed,
`php_stream_wrapper_log_error` signature changed.
